# Public Brand API Contract

## Status

This document defines the first public API contract for the STDS brand-facing
lightweight backend.

The first version is Markdown documentation only. OpenAPI and generated code are
deferred, but the contract is structured around paths, methods, parameters,
response fields, examples, and errors so it can be migrated to OpenAPI later.

The API is public and read-only. It must not expose admin workflows, core STDS
operational tables, tenant, lease, billing, accounting, repair, attachment, or
scheduler behavior.

## Data Source Boundary

The service reads only approved brand-facing readonly views from the core STDS
database:

- `approved_brand_profile_v1`
- `approved_brand_faq_items_v1`
- `approved_brand_property_availability_v1`

The brand backend must not query core base tables directly unless a later GitHub
issue explicitly approves and documents that boundary.

## Shared Conventions

- Base path: `/api/v1`
- Format: JSON
- Public responses should expose only fields available from the approved views.
- Empty list endpoints return `200 OK` with an empty `items` array.
- Empty singleton endpoints return `200 OK` with a nullable object wrapper.
- Firebase Hosting rewrites, such as `/brand-api/**`, are deployment concerns
  and are not part of this service-path contract.

## Shared Error Response

All public API errors use the same response shape:

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Invalid request."
  },
  "request_id": "req_01HX0000000000000000000000"
}
```

### Error Fields

| Field | Type | Description |
| --- | --- | --- |
| `error.code` | string | Stable public error code in `UPPER_SNAKE_CASE`. |
| `error.message` | string | Safe public error message. |
| `request_id` | string | Request identifier from `X-Request-ID` or generated by the service. |

### Common Error Codes

| Code | Meaning |
| --- | --- |
| `VALIDATION_FAILED` | Request parameters are invalid. |
| `SERVICE_UNAVAILABLE` | A required dependency, such as the readonly database, is unavailable. |
| `INTERNAL_ERROR` | An unexpected server error occurred. |

## `GET /api/v1/brand/profile`

Returns the public brand profile singleton.

### Request Parameters

None.

### Data Source

`approved_brand_profile_v1`

### Response

`200 OK`

```json
{
  "profile": {
    "brand_name": "STDS",
    "contact_phone": "02-1234-5678",
    "contact_email": "hello@example.com",
    "contact_address": "台北市中正區範例路 1 號",
    "updated_at": "2026-05-15T12:00:00Z"
  }
}
```

If no approved profile row exists, return `200 OK` with `profile: null`.

```json
{
  "profile": null
}
```

### Response Fields

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `profile` | object | yes | Public brand profile. |
| `profile.brand_name` | string | no | Public brand name. |
| `profile.contact_phone` | string | yes | Public contact phone number. |
| `profile.contact_email` | string | yes | Public contact email. |
| `profile.contact_address` | string | yes | Public contact address. |
| `profile.updated_at` | string | no | Last profile update time in RFC 3339 format. |

## `GET /api/v1/brand/faqs`

Returns active public FAQ items ordered by `sort_order`.

### Request Parameters

None.

### Data Source

`approved_brand_faq_items_v1`

### Response

`200 OK`

```json
{
  "items": [
    {
      "question": "如何預約看房？",
      "answer": "請透過公開聯絡方式與我們確認可預約時段。",
      "sort_order": 10
    }
  ]
}
```

If no approved FAQ rows exist, return `200 OK` with an empty list.

```json
{
  "items": []
}
```

### Response Fields

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `items` | array | no | Public FAQ items. |
| `items[].question` | string | no | FAQ question. |
| `items[].answer` | string | no | FAQ answer. |
| `items[].sort_order` | integer | no | Display order from the approved view. |

## `GET /api/v1/properties/availability`

Returns public property availability summaries.

### Request Parameters

None.

### Data Source

`approved_brand_property_availability_v1`

### Response

`200 OK`

```json
{
  "items": [
    {
      "property_id": "00000000-0000-0000-0000-000000000000",
      "property_public_name": "北車館",
      "address": "台北市中正區範例路 1 號",
      "has_vacant_room": true
    }
  ]
}
```

If no approved property availability rows exist, return `200 OK` with an empty
list.

```json
{
  "items": []
}
```

### Response Fields

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `items` | array | no | Public property availability summaries. |
| `items[].property_id` | string | no | Property identifier from the approved view. |
| `items[].property_public_name` | string | no | Public-facing property name. |
| `items[].address` | string | no | Public property address from the approved view. |
| `items[].has_vacant_room` | boolean | no | Whether the property has at least one non-deleted vacant room. |

## OpenAPI Migration Notes

This contract intentionally avoids OpenAPI and generated code in the first
version. A later OpenAPI migration should be able to translate each endpoint
section into path, operation, response schema, example, and error schema entries
without changing the public API semantics documented here.
